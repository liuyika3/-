# 局域网访问说明

## ⚠️ 重要提示

如果遇到"拒绝连接"的问题，请按以下步骤操作：

1. **停止当前服务器**（如果正在运行）
   - 在服务器控制台按 `Ctrl+C` 停止服务器

2. **添加防火墙规则**（重要！）
   - 右键 `添加防火墙规则.bat`，选择"以管理员身份运行"
   - 这会允许端口 5000 的入站连接

3. **重新启动服务器**
   - 双击 `启动服务器.bat` 重新启动

4. **验证监听地址**
   - 运行 `python 测试局域网连接.py` 测试连接
   - 或在命令行运行：`netstat -an | findstr ":5000"`
   - 应该看到 `0.0.0.0:5000` 而不是 `127.0.0.1:5000`

## 启动服务器

双击运行 `启动服务器.bat` 文件，或运行：
```bash
python start_server.py
```

**重要**：确保服务器启动时显示 `监听地址: 0.0.0.0:5000`，而不是 `127.0.0.1:5000`

## 访问地址

服务器启动后，控制台会显示两个访问地址：

1. **本地访问**：`http://localhost:5000`
   - 仅在本机访问

2. **局域网访问**：`http://[你的IP地址]:5000`
   - 局域网内其他设备可以通过此地址访问
   - 例如：`http://10.100.14.58:5000` 或 `http://100.64.164.2:5000`

## 获取本机 IP 地址

如果控制台没有显示 IP 地址，可以通过以下方式获取：

**Windows PowerShell:**
```powershell
ipconfig | findstr /i "IPv4"
```

**Windows CMD:**
```cmd
ipconfig | findstr /i "IPv4"
```

## 防火墙配置

如果局域网内其他设备无法访问，请检查 Windows 防火墙：

1. 打开"Windows Defender 防火墙"
2. 点击"高级设置"
3. 确保端口 5000 的入站规则已启用

或者运行以下命令（需要管理员权限）：
```cmd
netsh advfirewall firewall add rule name="Flask Server" dir=in action=allow protocol=TCP localport=5000
```

## 注意事项

1. 确保服务器和客户端设备在同一局域网内
2. 确保防火墙允许端口 5000 的入站连接
3. 如果使用 VPN，可能需要配置 VPN 路由规则
4. 服务器关闭后，局域网访问将不可用

## 测试访问

在其他设备（手机、平板、其他电脑）的浏览器中输入：
```
http://[服务器IP地址]:5000
```

例如：`http://10.100.14.58:5000`
