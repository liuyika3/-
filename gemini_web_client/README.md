# Gemini Web 客户端

一个现代化的 Web 界面，支持多种 Google Gemini 模型的对话。

## ✨ 功能特性

- 🤖 **多模型支持**：Gemini 2.5 Pro、Flash、1.5 Pro 等
- 💬 **智能记忆**：自动保存对话历史和上下文，支持可调节的上下文窗口
- 📎 **文件上传**：支持多种格式文件分析（txt、md、pdf、doc、json、py等）
- 📝 **大容量输入**：支持80万字符输入，适合长文本分析
- ⚙️ **参数调节**：可调节创造性、Token限制、上下文窗口等参数
- 🔄 **自动保存**：系统提示词和设置自动保存
- 📱 **响应式设计**：完美支持桌面和移动端
- 🎨 **现代化UI**：美观的渐变设计和动画效果
- 📝 **Markdown支持**：支持代码块、粗体、斜体等格式
- 💾 **本地存储**：设置和对话历史自动保存到本地

## 🚀 快速开始

### 方法1：直接打开
1. 双击 `start.html` 文件
2. 点击"启动客户端"按钮
3. 在设置中输入您的 Google AI API Key
4. 选择模型开始对话

### 方法2：本地服务器
```bash
# 使用 Python 启动本地服务器
python -m http.server 8000

# 或使用 Node.js
npx http-server

# 然后访问 http://localhost:8000
```

## 🔑 获取 API Key

1. 访问 [Google AI Studio](https://aistudio.google.com/app/apikey)
2. 登录您的 Google 账户
3. 点击"Create API Key"
4. 复制生成的 API Key

## 📋 支持的模型

## ⚙️ 设置说明

### 基本设置
- **API Key**：您的 Google AI API Key
- **模型选择**：选择要使用的 Gemini 模型
- **创造性**：控制回答的创造性程度 (0-1)
- **最大Token数**：限制单次回答的长度
- **系统提示词**：自定义AI的角色和行为

### 高级功能
- **智能记忆**：自动保存对话历史，支持可调节的上下文窗口（默认20轮）
- **文件上传**：点击📎按钮上传文件，支持多种格式
- **参数调节**：实时调整模型参数和上下文窗口大小
- **自动保存**：系统提示词修改后自动保存
- **清空对话**：重置对话历史和附件

## 🎨 界面预览

- **现代化设计**：渐变背景和卡片式布局
- **实时反馈**：加载动画和状态提示
- **响应式布局**：自适应不同屏幕尺寸
- **暗色主题**：护眼的深色配色方案

## 📎 文件上传功能

### 支持的文件格式
- **文本文件**：.txt, .md, .json, .py, .js, .html, .css, .csv
- **Word文档**：.docx（使用mammoth.js库提取纯文本）
- **PDF文档**：.pdf（转换为Base64格式，AI尝试解析）

### 使用方法
1. 点击输入框左侧的📎按钮
2. 选择要上传的文件（支持多选）
3. 文件会自动读取并显示在输入框上方
4. 可以点击❌按钮移除单个文件
5. 发送消息时，文件内容会自动包含在请求中

### 文件处理方式
- **docx文件**：使用mammoth.js库提取纯文本内容，AI可以直接理解
- **PDF文件**：转换为Base64格式，AI尝试解析内容
- **文本文件**：直接读取UTF-8编码内容
- **其他文件**：转换为Base64格式

### 文件限制
- 单个文件最大10MB
- 支持同时上传多个文件
- 自动检测文件类型和MIME类型
- 详细的错误提示和状态反馈
