API & 工具使用清单

万物教练后端服务器 (server.cjs) 提供 9 个核心 API 端点，支持 5 大 Showcase 场景的数据抓取。数据来源主要为 Apify Actor 及各类免费开放 API。

核心 API 端点状态

API 端点 数据源 / Actor 用途 状态
POST /api/food Open Food Facts 食品营养成分及配料信息 (700万+ 库) ✅ 稳定
POST /api/pubmed NCBI PubMed 权威科学文献及医学论文检索 ✅ 稳定
POST /api/reddit HackerNews / Algolia 社区真实讨论反馈 (替代失效的 Reddit API) ✅ 稳定
POST /api/wikipedia Wikipedia API 目的地及名词背景资料 ⚠️ 限制
POST /api/shopping Apify: Amazon/Google 商品价格及购买选项 ✅ 稳定
POST /api/youtube-search Apify YouTube Scraper 搜索相关教育及 Vlog 视频 ✅ 稳定
POST /api/transcript Apify YouTube Transcript 提取视频字幕并进行词汇频率分析 ✅ 稳定
POST /api/jobs Apify: Indeed Scraper 获取最新招聘职位及薪资分布 ✅ 稳定
POST /api/hotels Apify: Booking Scraper 检索当地酒店、评分及价格信息 ✅ 稳定
POST /api/exercises wger.de API 开源健身动作库及肌肉部位数据 ✅ 稳定
