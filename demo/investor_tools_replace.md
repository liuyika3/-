### 一、投资人向（偏“工具属性/基础设施属性”）

| 工具型 Idea | 工具属性（为什么更好融资） | 30秒融资叙事 |
| --- | --- | --- |
| **1) Universal Context Connector（全域上下文连接器）** | 打通 IM、邮件、日历、文档、浏览器行为流，统一成可检索的“个人上下文层” | 不是做一个助手，而是做“个人数据中间件”；上层可长出无数 Agent 应用。 |
| **2) Action Orchestrator（跨App动作编排器）** | 把“建议”变成“可执行动作链”：读消息→生成回复→排日程→发提醒→跟踪结果 | 从“会说”升级到“会做”，工具价值可被企业和个人双端采买。 |
| **3) Personal Memory Graph（个人记忆图谱引擎）** | 每次对话/决策都沉淀为节点关系，可回放、可检索、可推理 | 护城河不在模型，而在长期用户记忆资产；越用越准，迁移成本高。 |
| **4) Decision Copilot SDK（决策副驾SDK）** | 向外提供SDK/API：任何产品都能接入“风险评估+建议分支+执行闭环” | 直接具备平台潜力，故事从 C 端工具变成 B2B2C 基础能力。 |
| **5) Social Risk Engine（社交风险引擎）** | 输入聊天文本即可输出误解风险、情绪强度、关系波动指标 | 标准化程度高，能沉淀成评分系统，具备可计费、可审计属性。 |
| **6) Behavior Firewall（行为防火墙）** | 在高风险时刻拦截冲动操作（冲动消费、冲动发言、冲动承诺） | 类似安全软件范式，用户愿意为“避免重大后悔”持续付费。 |
| **7) Persona Toolkit（人格工具箱）** | 可配置的人格策略模块：谈判、面试、管理、亲密关系，各自有模板和指标 | 从“单点功能”变成“可组合工具集”，适合做订阅分层和企业版。 |
| **8) Outcome Analytics Console（结果分析控制台）** | 对每次建议是否被执行、是否有效做归因分析，形成ROI闭环看板 | 具备可量化价值，能直接回答投资人“效果怎么证明”。 |

#### 融资角度统一话术（工具导向）

- 我们做的是“**行为决策基础设施**”，不是单一聊天产品。  
- 我们的核心资产是“**上下文连接 + 动作执行 + 结果归因**”三层工具链。  
- 这套工具链既可服务 C 端教练，也可被 B 端产品调用，具备平台化天花板。
