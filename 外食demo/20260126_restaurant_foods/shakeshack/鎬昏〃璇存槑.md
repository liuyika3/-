## 📈 数据统计

### 整体统计
- **总记录数**: 266 条
- **有描述**: 246 条 (92.5%)
- **有价格**: 63 条 (23.7%)
- **有图片路径**: 224 条 (84.2%)
- **有营养数据**: 43 条 (16.2%)

### 数据来源
1. **营养数据** (43条): 来自 PDF 营养信息表
2. **浏览器数据** (223条): 来自网页爬取的额外项（描述、图片、价格）

### 数据完整性
- **完整数据**（描述+图片+营养）: 约 40+ 条
- **部分数据**: 大部分记录有描述和图片，但价格和营养数据较少

## 🎯 使用建议

### 1. 查看完整数据
```python
import pandas as pd

df = pd.read_excel('ShakeShack_总表.xlsx', sheet_name='总表')

# 查看有完整数据的记录
complete = df[
    df['description'].notna() & 
    df['local_image_path'].notna() & 
    df['calories'].notna()
]
print(f"完整数据: {len(complete)} 条")
```

### 2. 按分类查看
```python
# 按分类统计
category_stats = df.groupby('category').agg({
    'food_name': 'count',
    'calories': lambda x: sum(1 for v in x if v),
    'local_image_path': lambda x: sum(1 for v in x if v),
}).rename(columns={
    'food_name': '数量',
    'calories': '有营养',
    'local_image_path': '有图片'
})
```

### 3. 查找特定食物
```python
# 查找 ShackBurger
shackburger = df[df['food_name'].str.contains('ShackBurger', case=False, na=False)]
print(shackburger[['food_name', 'calories', 'local_image_path', 'description']])
```

### 4. 查看图片
所有图片已下载到 `images/` 目录，`local_image_path` 字段指向本地文件路径。

## 📝 注意事项

1. **价格数据**: 价格信息较少（23.7%），因为网页上价格可能动态加载或需要选择门店
2. **营养数据**: 只有 43 条来自 PDF，其他浏览器爬取的项可能没有营养信息
3. **图片匹配**: 图片通过名称模糊匹配，可能不完全准确
4. **描述**: 大部分来自网页爬取，格式可能包含换行符
