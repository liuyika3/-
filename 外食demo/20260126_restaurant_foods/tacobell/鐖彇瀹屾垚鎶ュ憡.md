- 官网营养信息页面使用 iframe 嵌入第三方网站(nutritionix.com)
- 需要单独访问每个菜品详情页并处理复杂的JavaScript渲染
- 为了爬取效率,优先保证基本信息和图片的完整性

### 🔧 如需补充营养数据

可以修改 `scraper_final.py` 中的代码,取消注释营养信息获取部分:

```python
# 第2步: 为每个菜品补充营养信息
logger.info("\n开始获取详细营养信息...")
for idx, item in enumerate(self.all_items, 1):
    if idx % 10 == 0:
        logger.info(f"进度: {idx}/{len(self.all_items)}")
    self.enrich_with_nutrition(item)
    time.sleep(0.5)
```

注意:这会显著增加爬取时间(预计增加2-3小时)。
