## 关于过敏信息和成分说明

### 过敏信息
Taco Bell 的过敏信息页面 (`/nutrition/allergen-info`) 使用 Nutritionix 的交互式工具。用户需要选择要避免的过敏原,然后系统会显示不含这些过敏原的食物列表。

由于这是一个交互式筛选工具而非静态数据表,无法直接爬取完整的过敏原矩阵。如需获取特定过敏原信息,可以通过以下 URL 查询:
```
https://www.nutritionix.com/taco-bell/menu/special-diets/premium?allergenTags[]=allergen_contains_eggs&allergenTags[]=allergen_contains_milk
```

### 成分说明
成分说明页面 (`/nutrition/ingredients`) 同样使用 Nutritionix 的嵌入式工具,需要点击具体菜品才能查看成分。
