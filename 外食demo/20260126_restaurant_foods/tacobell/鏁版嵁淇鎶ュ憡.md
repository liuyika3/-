# Taco Bell 数据修正报告

## 问题发现

用户发现 **Cinnabon Delights® 2 Pack** 的卡路里数据错误:
- 网页显示: **170 kcal**
- Excel 错误显示: **1010 kcal** (这是 12 Pack 的数据)

## 问题原因

原来的模糊匹配算法在匹配 "Cinnabon Delights® 2 Pack" 时,错误地匹配到了 "Cinnabon® Delights™ (12 Pk)" 的营养数据,因为:
1. 名称相似度较高
2. 没有验证卡路里数据是否一致

## 修复方案

1. **改进匹配算法**: 在名称匹配时,同时验证卡路里数据
2. **优先使用官方 API 数据**: 卡路里数据优先使用 Taco Bell 官方 API 返回的 `calories` 字段
3. **卡路里验证**: 只有当 Nutritionix 的卡路里与 API 卡路里差异小于 50 时,才使用 Nutritionix 的完整营养数据
