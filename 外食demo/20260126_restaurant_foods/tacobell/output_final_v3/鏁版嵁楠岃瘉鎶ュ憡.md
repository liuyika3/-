## 问题分析

### Cantina Chicken Soft Taco 数据差异

Excel 中显示 260,但网页提取到 330。可能的原因:
1. 官方 API 数据与网页数据不同步
2. Excel 中匹配到了错误的营养数据
3. 网页上的卡路里是包含某些配料的版本

**建议**: 需要重新检查这个菜品的数据来源和匹配准确性。

### 酱料单品数据说明

Avocado Ranch Sauce 在单独购买页面显示 0 Cal,但作为添加项时显示 "Adds 80 Cal"。Excel 中的 240 可能是:
- Nutritionix 数据库中一整包酱料的热量
- 与官方 API 数据不一致

这不是错误,而是数据来源和计量方式的差异。

## 建议

1. **修正 Cantina Chicken Soft Taco**: 检查这个菜品的数据,确认正确的卡路里值
2. **酱料数据标注**: 对于酱料类单品,建议在 Excel 中添加备注说明其为完整份量热量
3. **定期验证**: 建议定期(如每月)随机抽样验证数据准确性
4. **多数据源对比**: 当官方 API 和网页数据不一致时,应以网页数据为准
