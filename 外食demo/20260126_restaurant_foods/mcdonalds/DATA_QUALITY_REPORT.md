## 🔧 技术问题分析

### 数据提取方式

使用Playwright浏览器自动化爬取,数据格式如下:

```yaml
- role: listitem
  name: "Sodium: 1060mg (46 % DV) 1060milligrams (46 Percent Daily Values )"
  ref: e137
```

### 解析挑战

1. **文本格式复杂**: 同一文本中包含多个数字(数值、百分比、重复的数值)
2. **单位不统一**: g, mg, mcg 混用
3. **重复信息**: "1060mg" 和 "1060milligrams" 重复出现

### 解决方案

需要更精确的正则表达式:
```python
# 错误的方法
re.search(r'(\d+(?:\.\d+)?)', text)  # 会匹配第一个数字

# 正确的方法
re.search(r'Sodium:\s*(\d+)mg', text)  # 精确匹配"Sodium: XXXmg"
```
