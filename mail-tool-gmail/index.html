Gmail 账号切换与授权向导

为了保证你可以用任何 Gmail 账号群发，我们需要进行一次简单的 API 配置。

1 确定你要用哪个邮箱发件？

我们需要把你将要登录的邮箱，先加入到 Google Cloud 的白名单里，否则 Google 会拦截你。

💡 把上面这个邮箱填好并复制下来，下一步会用到。

2 去 Google Cloud 把邮箱加白名单

打开并登录 Google Cloud OAuth 同意屏幕 ↗ (记得挂全局代理)

如果是第一次进，它可能会让你 新建项目 (Create Project)，名字随便起。

然后 User Type 选 External (外部)，填一下必填的 App 名称和支持邮箱。

⚠️

最关键的一步 (防止 403 拒绝访问)：

在这个页面的下面找到 Test users (测试用户)，点击 + ADD USERS，把你刚才第一步填的那个邮箱加进去，点保存！

3 拿到登录钥匙 (Client ID / Secret)

1. 点击左侧菜单的 Credentials (凭据)，点击顶部的 + Create Credentials > OAuth client ID。

2. Application type 选 Web application。

3. 在 Authorized redirect URIs (已获授权的重定向 URI) 这里，点击 ADD URI，把下面这两行分别粘贴进去：
http://127.0.0.1:3012/oauth/callback http://localhost:3012/oauth/callback

4. 点击底部的 Create，它会弹出一个窗口，把你看到的 Client ID 和 Client Secret 复制下来。

4 填入钥匙，发起登录

如果你之前已经成功填过这俩个钥匙，它们可能已经保存在本地了，此时你只需要直接点下面那个蓝色大按钮去授权即可，不需要重复填。

跳转后，如果提示 "Google hasn't verified this app"，点击左下角的 "Advanced (高级)" -> "Go to ... (unsafe)" 即可通过。
