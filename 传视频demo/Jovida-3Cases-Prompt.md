# 提示词总结：AI 康复教练 (Jovida) 三大核心场景移动端 UI 还原

## 角色与目标
你是一个顶级的资深前端工程师兼 UI/UX 设计专家。你需要使用 React + Tailwind CSS 制作一个高保真的移动端 Web App（AI 康复教练）。
请严格遵循以下设计规范和具体场景拆解，生成单文件结构（如 App.tsx）的代码。

## 全局设计系统 (Design System)
- **容器与布局**:
  - 纯移动端优先设计，最大宽度 `375px`，居中显示，隐藏系统滚动条。
  - 页面背景色：`#E7E9EC`。
  - 页面两边距（Padding）：始终保持 `16px`。
- **排版与字体 (Typography)**:
  - 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "Urbanist", "Noto Sans SC", sans-serif;`。
  - 全局加入 `font-variation-settings: 'wdth' 100;` 增加字体质感。
  - 数字和英文着重使用 `Urbanist`。
  - 文本层级严格使用 `rgba` 透明度（如黑色的 40% `text-[rgba(0,0,0,0.4)]`），禁用直接写灰色的 HEX 值。
- **圆角规则 (Border Radius)**:
  - 外部卡片：`24px`。
  - 内部子卡片/按钮：`16px`。
  - 必须满足“内圆角 = 外圆角 - Padding” 的视觉规则。
  - 输入框（Chat Input）：`32px` 的全圆角。
- **组件样式 (Component Styles)**:
  - **大卡片 (Surface)**: 背景色 `#F2F2F2`。外层避免生硬阴影，使用柔和阴影配合白边：`border-white shadow-[0_4px_24px_rgba(0,0,0,0.04)]`。
  - **内嵌子卡片**: 背景色 `#FFFFFF`。
  - **主行为按钮 (Primary CTA)**: 背景黑灰渐变 `bg-gradient-to-b from-black to-[#575757]`。文字颜色为荧光绿 `#ACFF4E`。高度至少 `44px`，圆角 `100px`。
  - **图标**: 仅使用 `lucide-react`。
  - **聊天框底部**: 悬浮在底部，输入区白底 `bg-white`，全圆角 `rounded-[32px]`，边框白线 `border-white`。

## 场景 1：SLEEP (昨晚睡眠报告)
**UI 结构**：
1. **主卡片**：包含标题“昨晚睡眠报告”及副标题。右上角状态标签（背景 `#FFEBCB`，文字 `#FF9D00`，圆角 `8px`，内容“评分 58”）。
2. **睡眠阶段块**：内部白底卡片。
   - 左侧图标（渐变红底 `from-[#FF6767] to-[#FFADAD]`的月亮）。
   - 右侧分两行：深睡时长（红色强调字 `text-[#FF6767]`，Urbanist字体）和分析文字。
3. **今日修复建议 (Todos)**：
   - Checkbox 列表。
   - 白底内部卡片，左侧圆圈，右侧任务名。
   - 勾选后，圆圈变荧光绿 `#ACFF4E`，带黑色勾。

## 场景 2：MORNING (晨间 Routine)
**UI 结构**：
1. **主卡片**：包含标题“今日晨间唤醒”。右上角绿色标签（背景 `#E8FFD1`，文字 `#52A600`，内容“进度 1/3”）。
2. **任务列表 (Checklist)**：
   - 纵向排列任务卡片（白底）。
   - 选中状态：圆圈背景变 `#ACFF4E`，无边框或同色边框，黑色勾。文字变为半透明黑（`rgba(0,0,0,0.4)`）并加删除线（line-through）。

## 场景 3：HEALTH (健康外食)
**UI 结构**：
1. **双栏选项 (Tabs)**：主卡片顶部有 Tab（如“Wagas”和“Manner”）。当前选中项白底带轻微阴影，未选中项融入底色。
2. **推荐菜品卡片**：
   - 白底内嵌卡片。
   - 卡路里高亮展示：**黑底荧光黄字**（背景 `bg-black`，文字 `#FFA61A`），圆角 `8px`。
   - 点评标签：绿色的“高蛋白”等小 Tag。
3. **主操作按钮**：卡片底部 CTA（“生成点单口令”），黑底渐变+荧光绿字。

## 整体界面框架 (App Shell)
- **对话流 (Chat Stream)**：
  - 教练气泡：背景 `#F2F2F2`，圆角 `24px`，无头像，文字颜色为纯黑，大小 `17px`。
  - 用户气泡：黑色背景，白色文字。
  - 将 3 个 Case 动态渲染插入到教练的气泡流中。
- **发送按钮**：圆形，黑灰渐变底 `from-black to-[#575757]`，中间有荧光绿的 ArrowUp 箭头。
